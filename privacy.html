File Org privacy policy

File Org is the internal document control app of Deltech Parking Systems and Solutions Inc., Cebu City, Philippines. It is used only by Deltech employees.

What File Org accesses

  • Your Google name, email address and profile photo, to show who uploaded, edited or sent each file and message.
  • The company's File Org folder in Google Drive, where reports are stored, and the File Org Database Google Sheet inside it, where the file list, chat and activity are kept.

Where your data goes

File Org runs entirely in your browser. It talks only to Google Drive and Google Sheets with your permission. There is no File Org server, and no data is sold, shared with third parties or used for advertising.

File Org only works inside the File Org folder that the company shares with you. It does not read your other Drive files.

Removing access

You can remove File Org's access at any time in your Google Account under Third-party apps and services. Files you uploaded stay in the company's File Org folder.
